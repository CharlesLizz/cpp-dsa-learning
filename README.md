# C/C++ Data Structures & Algorithms

记录个人 C/C++ 基础、数据结构与算法的学习过程，包括知识笔记、代码实现、算法练习与 PTA 题目。

本仓库以 **C/C++ 基础 → 数据结构 → 算法 → 综合应用** 为学习主线，通过视频课程、代码实践和问题分析，逐步掌握常见数据结构与算法的原理及实现方法。

## 📚 学习内容

- **C/C++ 基础**：基本语法、数组、函数、指针、结构体、动态内存管理与文件操作。
- **数据结构**：线性表、栈、队列、串、树、图等常见数据结构。
- **算法分析**：算法设计、时间复杂度、空间复杂度及性能分析。
- **查找与排序**：常见查找算法、内部排序与外部排序。
- **PTA 练习**：通过编程题巩固基础知识，提高独立分析与解决问题的能力。

## 🧩 C/C++ 基础学习记录

已完成 C 语言基础课程的系统学习，并通过代码练习巩固相关知识。

### 1. 基础语法与程序结构

- 基本数据类型、常量与类型转换。
- `printf`、`scanf` 与格式控制符。

- 顺序结构、条件分支与循环结构。

- **动态顺序表**：初始化、容量检查、动态扩容、头尾插入与删除、指定位置插入与删除、查找及销毁。

- 使用 Visual Studio 编写、编译和调试程序。

## 📝 学习记录规范

为方便后续复习、查错与整理，学习过程中尽量遵循以下原则：

- **理解优先**：先理解知识点与算法思路，再动手编写代码。
- **独立实现**：尽量先自行完成，再通过调试和对比改进实现。
- **笔记与代码并行**：记录重要概念、实现思路、关键细节与典型问题。
- **关注边界条件**：检查空结构、越界访问、内存管理等情况。
- **分析算法复杂度**：对重要操作与算法分析时间复杂度和空间复杂度。
- **保留问题记录**：总结错误原因、调试过程与改进思路。
- **逐步完善**：按实际学习进度更新目录，不刻意追求一次性整理完整。
