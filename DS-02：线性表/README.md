# 第二章 线性表

## 2.1线性表的定义和基本操作

线性表是具有相同数据类型的n（n>=0）个数据元素的有限序列，其中n为表长，当n=0时，线性表是一个空表。

#### 基本操作

- InitList（&L）：初始化表，构造空的线性表，分配内存空间
- DestroyList（&L）：销毁操作，销毁线性表并释放线性表L所占用的内存空间

	也就是`从无到有`和`从有到无`
- ListInsert（&L,i,e）：插入操作，在表L的低i个位置上插入指定元素e
- ListDelete（&L,i）：删除操作，删除表L中第i个位置的元素
- LocateElem（L,e）：按值查找
- GetElem（L,i）：按位查找

	**Tips**：	 其实基本操作也就包括创建，删除，增删改查

	还有其他操作，此处省略

## 2.2.1顺序表的定义

### 顺序表——用顺序存储的方式实现线性表，把逻辑上相邻的元素存储在物理位置上也相邻的存储单元中

	如何知道一个数据元素大小？
	C语言可以使用 sizeof方法

#### 顺序表的实现方式1：**静态分配**

- 表的长度大小确定后不能轻易改变，实际上是在内存中开辟了一整片连续的存储空间
- 使用静态数组实现

**case:**
```c
#include <stdio.h>
#define MaxSize 10        //定义最大长度
typedef struct{
    int data[MaxSize];    //用静态的“数组”存放数据元素
    int length;           //顺序表的当前长度
}SqList;                  //顺序表的类型定义

//基本操作——初始化一个顺序表
void InitList(SqList &L){
    for(int i=0; i<MaxSize; i++)
        L.data[i]=0;      //将所有数据元素设置为默认初始值
    L.length=0;           //顺序表初始长度为0
}

int main() {
    SqList L;             //声明一个顺序表
    InitList(L);          //初始化顺序表
    //...未完待续，后续操作
    return 0;
}
```

如果没有设置数据元素的默认值，内存中可能会有遗留的“脏数据”

给顺序表中每个元素设置默认值这一步可以省略，一般使用时不会直接使用MaxSize，而是使用length

#### 顺序表的实现方式2：**动态分配**

- 使用动态数组`malloc函数`来实现
    
- 顺序表存满时，可以再用malloc动态拓展顺序表的最大容量
- 需要将数据元素复制到新的存储区域，并用free函数释放原区域

### 顺序表的特点
- 随机访问，常数级的时间复杂度，可以在O(1)时间内找到第i个元素
- 存储密度高，每个节点只存存储数据元素
- 拓展容量不方便（即便采用动态分配的方式实现，拓展长度的时间复杂度也比较高）
- 插入、删除操作不方便，需要移动大量元素
