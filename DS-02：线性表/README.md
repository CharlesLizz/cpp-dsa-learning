# 第二章 线性表

## 2.1 线性表的定义和基本操作

### 2.1.1 线性表的定义

线性表是具有相同数据类型的 \(n\) 个数据元素的有限序列，其中 \(n\) 为表长。当 \(n=0\) 时，线性表是空表。

线性表的特点：

- 元素具有相同的数据类型。
- 元素之间存在逻辑上的先后顺序。
- 除第一个元素外，每个元素有且仅有一个直接前驱。
- 除最后一个元素外，每个元素有且仅有一个直接后继。
- 线性表的长度可以为 0。

### 2.1.2 线性表的基本操作

| 操作 | 含义 |
|---|---|
| `InitList(&L)` | 初始化表，构造空的线性表 |
| `DestroyList(&L)` | 销毁线性表，释放其占用的资源 |
| `ListInsert(&L, i, e)` | 在第 `i` 个位置插入元素 `e` |
| `ListDelete(&L, i, &e)` | 删除第 `i` 个位置的元素，并用 `e` 返回被删除的值 |
| `LocateElem(L, e)` | 按值查找，返回满足条件的元素位置 |
| `GetElem(L, i)` | 按位查找，获取第 `i` 个位置的元素 |
| `ListLength(L)` | 获取线性表长度 |
| `Empty(L)` | 判断线性表是否为空 |

注：不同教材对操作的参数、返回值可能有不同规定。

**注意：** 基本操作不仅包括增删改查，还包括初始化、销毁、判空、求长度等操作。

## 2.2.1 顺序表的定义

**顺序表是用顺序存储方式实现的线性表。**

顺序存储是指将逻辑上相邻的元素存储在物理位置上也相邻的存储单元中。

由于元素连续存储，可以通过首元素的地址和元素下标直接计算目标元素的位置。

#### 顺序表的基本结构

```c
#define MaxSize 10

typedef struct {
    int data[MaxSize];  // 存储数据元素
    int length;         // 当前长度
} SqList;
```

- `data`：存放线性表中的元素。
- `MaxSize`：顺序表的最大容量。
- `length`：顺序表当前实际存放的元素个数。

**注意：** `length` 表示当前元素个数，不是数组的最大容量。

### 顺序表的实现方式

#### 1. 静态分配

使用固定长度的数组存储数据，数组容量在定义时确定。

```c
#include <stdio.h>

#define MaxSize 10

typedef struct {
    int data[MaxSize];
    int length;
} SqList;

void InitList(SqList *L) {
    L->length = 0;
}

int main(void) {
    SqList L;
    InitList(&L);

    return 0;
}
```

特点：

- 数组容量固定，不能直接扩大。
- 初始化时将 `length` 设置为 `0`，表示当前没有元素。
- 如果需要使用数组元素，应确保它们已经被赋值。
- 可以将整个数组初始化为 `0`，但这不是所有场景下都必须执行的操作。

**注意：** 未初始化的局部变量可能具有不确定的值，但不代表其中一定是历史遗留的“脏数据”。

#### 2. 动态分配

使用动态内存分配函数申请存储空间，常见方式是使用 `malloc`，并通过 `free` 释放空间。

特点：

- 存储空间在运行过程中申请。
- 可以在容量不足时申请更大的空间。
- 扩容通常需要将原有元素复制到新的存储区域。
- 使用完毕后需要释放动态申请的内存。

如果使用 `realloc` 扩容，还需要正确处理扩容失败的情况，避免丢失原有内存地址。

**注意：** 动态分配不代表容量可以无限增长，扩容仍然受内存资源限制。

### 顺序表的特点

1. **随机访问**：可以根据下标直接访问第 `i` 个元素，时间复杂度为 `O(1)`。
2. **存储密度高**：元素连续存储，不需要为每个元素额外保存链表指针。
3. **扩容不方便**：静态分配容量固定；动态分配虽然可以扩容，但可能需要申请新空间并复制元素。
4. **插入和删除不方便**：在中间位置操作时，通常需要移动大量元素。

## 2.2.2_1 顺序表的插入与删除

### 插入操作

`ListInsert(&L, i, e)`：在顺序表的第 `i` 个位置插入元素 `e`。

假设顺序表当前有 `length` 个元素，插入位置为 `i`，则：

- 合法插入位置：`1 <= i <= length + 1`。
- 插入前必须确保顺序表尚有剩余容量。
- 为避免覆盖原有数据，需要从后向前移动元素。
- 插入完成后，`length` 加 `1`。

#### 插入算法

以下代码使用 C 语言指针传参，且假设 `SqList` 采用固定容量数组实现。

```c
#include <stdbool.h>

bool ListInsert(SqList *L, int i, int e) {
    // 检查插入位置是否合法
    if (i < 1 || i > L->length + 1) {
        return false;
    }

    // 检查顺序表是否已满
    if (L->length >= MaxSize) {
        return false;
    }

    // 从后向前移动元素
    for (int j = L->length; j >= i; j--) {
        L->data[j] = L->data[j - 1];
    }

    // 插入新元素
    L->data[i - 1] = e;
    L->length++;

    return true;
}
```

#### 为什么必须从后向前移动？

例如，原顺序表为：

`[10, 20, 30, 40]`

在第 `2` 个位置插入 `99`。

需要先将 `40`、`30`、`20` 依次向后移动，再把 `99` 放到对应位置。

结果：

`[10, 99, 20, 30, 40]`

如果从前向后移动，可能会覆盖还没有移动的数据。

### 删除操作

`ListDelete(&L, i, &e)`：删除顺序表中第 `i` 个位置的元素，并返回被删除的值。

合法删除位置：

`1 <= i <= length`

删除过程：

1. 检查删除位置是否合法。
2. 保存被删除的元素。
3. 将被删除元素后面的元素依次向前移动。
4. 将 `length` 减 `1`。

#### 删除算法

```c
#include <stdbool.h>

bool ListDelete(SqList *L, int i, int *e) {
    // 检查删除位置是否合法
    if (i < 1 || i > L->length) {
        return false;
    }

    // 保存被删除的元素
    *e = L->data[i - 1];

    // 后续元素向前移动
    for (int j = i; j < L->length; j++) {
        L->data[j - 1] = L->data[j];
    }

    L->length--;

    return true;
}
```

例如，原顺序表为：

`[10, 20, 30, 40]`

删除第 `2` 个元素 `20` 后：

`[10, 30, 40]`

删除后只需要将 `length` 减 `1`，不必专门清空最后一个数组位置，因为该位置已经不属于当前顺序表的有效元素范围。

### 插入与删除的复杂度

| 操作 | 时间复杂度 | 原因 |
|---|---|---|
| 按位访问 | `O(1)` | 可以直接计算元素位置 |
| 插入到表头 | `O(n)` | 需要移动原有元素 |
| 插入到表尾 | `O(1)` | 有剩余容量时不需要移动元素 |
| 删除表头元素 | `O(n)` | 后续元素需要前移 |
| 删除表尾元素 | `O(1)` | 只需调整表长 |

上述复杂度针对固定容量顺序表，且不计入扩容成本；插入和删除的具体开销还与操作位置有关。

## 2.2.2_2 顺序表的查找操作

### 按位查找

也就是获取表中的第i个元素的值

可以简单的用以下代码实现

```
ElemType GetElem(SeqList L,int i)
{
    return L.data[i-1];
}

```
又由于顺序表的各个数据元素在内存中连续存放，因此可以根据起始地址和数组元素大小立即找到第i个元素

这叫“随机存取”特性，那么该算法的时间复杂度就是简单的 `O(1)`

### 按值查找

在表中查找具有给定关键字值的元素

可以通过简单循环实现，如果该位置的值等于给定的值，则返回其位序

```c
int LocateElem(SeqList L,int e){
    for(int i=0;i<L.length;i++)
        if(L.data[i] == e)
            return i+1;
    return 0;
}
```
但是如果值是一个复杂的类型，比如结构体，则不能通过简单的 `==` 来判断元素是否相等

如果是结构体，必须分别进行对比结构体中的各个分量是否相等，来进一步判断两个结构体变量是否相等

至少c语言不可以

**Tips**：数据结构这门课在考研初试时，手写代码（伪代码）可以直接用“==”，无论ElemType是基本数据类型还是结构类型

## 2.3.1 单链表的定义（如何用代码实现）

用链式存储实现的统称为链表

### 什么是单链表？

每个节点除了存放数据元素外，还要存储指向下一个节点的指针

- 单链表的有点：不要求大片连续空间，改变空间方便
- 要耗费一定的空间存放指针、地址

### 定义一个单链表

**case:不带头节点的情况**
```c
typedef struct LNode {				//定义单链表节点数据			
	ElemType data;			//每个节点存放一个数据元素
	struct LNode* next;		//指针指向下一个节点
}LNode, * LinkList;

//初始化一个空的单链表
_Bool InitList(LinkList* L)
{
	L = NULL;	//空表，暂时还没有任何节点
	return 1;
}

void test()
{
	LinkList L;		//声明一个指向单链表的指针
	//初始化一个空表
	InitList(&L);

	//。。。后续代码。。。
}
```
**case:带头节点的情况**

```c
//初始化一个单链表（带头节点）
_Bool InitList(LinkList* L)
{
	L = (LNode*)malloc(sizeof(LNode));
	if (L == NULL)
		return 0;
	L->next = NULL;		
	return 1;
}

void test()
{
	LinkList L;		//声明一个指向单链表的指针
	//初始化一个空表
	InitList(&L);

	//。。。后续代码。。。。
}
```
**注**：上述是伪代码，并未在C语言中真正实现功能，例如带头节点块中的 L->next = NULL;	未初始化，无法指向next

### 两种实现总结

- 不带头节点

    空表判断：L == NULL。写代码不方便

- 带头节点

    空表判断：L->next == NULL。写代码更方便
