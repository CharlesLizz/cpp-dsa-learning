# 第二章 线性表

## 2.1 线性表的定义和基本操作

### 2.1.1 线性表的定义

线性表是具有相同数据类型的 \(n\) 个数据元素的有限序列，其中 \(n\) 为表长。当 \(n=0\) 时，线性表是空表。

例如：

```text
L = [10, 20, 30, 40]
```

线性表的特点：

- 元素具有相同的数据类型。
- 元素之间存在逻辑上的先后顺序。
- 除第一个元素外，每个元素有且仅有一个直接前驱。
- 除最后一个元素外，每个元素有且仅有一个直接后继。
- 线性表的长度可以为 0。

### 2.1.2 线性表的基本操作

| 操作 | 含义 |
|---|---|
| `InitList(&L)` | 初始化表，构造空的线性表 |
| `DestroyList(&L)` | 销毁线性表，释放其占用的资源 |
| `ListInsert(&L, i, e)` | 在第 `i` 个位置插入元素 `e` |
| `ListDelete(&L, i, &e)` | 删除第 `i` 个位置的元素，并返回被删除的值 |
| `LocateElem(L, e)` | 按值查找，返回满足条件的元素位置 |
| `GetElem(L, i)` | 按位查找，获取第 `i` 个位置的元素 |
| `ListLength(L)` | 获取线性表长度 |
| `Empty(L)` | 判断线性表是否为空 |

注：不同教材对基本操作的参数、返回值可能有不同规定。上表中的 `&L` 是常见的算法描述写法；如果使用 C 语言实现，通常需要通过指针传参来修改线性表。

**注意：** 线性表的基本操作不仅包括增删改查，还包括初始化、销毁、判空、求长度等操作。

## 2.2.1 顺序表的定义

**顺序表是用顺序存储方式实现的线性表。**

顺序存储是指将逻辑上相邻的元素存储在物理位置上也相邻的存储单元中。

由于元素连续存储，可以通过首元素的地址和元素下标直接计算目标元素的位置。

### 顺序表的基本结构

```c
#define MaxSize 10

typedef struct {
    int data[MaxSize];  // 存储数据元素
    int length;         // 当前长度
} SqList;
```

- `data`：存放线性表中的元素。
- `MaxSize`：顺序表的最大容量。
- `length`：顺序表当前实际存放的元素个数。

**注意：** `length` 表示当前元素个数，不是数组的最大容量。

### 顺序表的实现方式

#### 1. 静态分配

使用固定长度的数组存储数据，数组容量在定义时确定。

```c
#include <stdio.h>

#define MaxSize 10

typedef struct {
    int data[MaxSize];
    int length;
} SqList;

void InitList(SqList *L) {
    L->length = 0;
}

int main(void) {
    SqList L;
    InitList(&L);

    return 0;
}
```

特点：

- 数组容量固定，不能直接扩大。
- 初始化时将 `length` 设置为 `0`，表示当前没有有效元素。
- 如果需要使用数组元素，应确保它们已经被赋值。
- 可以将整个数组初始化为 `0`，但这不是所有场景下都必须执行的操作。

**注意：** 未初始化的局部数组元素可能具有不确定的值，但不代表其中一定是历史遗留的“脏数据”。顺序表通过 `length` 判断哪些元素属于当前有效数据。

#### 2. 动态分配

使用动态内存分配函数申请存储空间，常见方式是使用 `malloc`，并通过 `free` 释放空间。

特点：

- 存储空间可以在程序运行过程中申请。
- 容量不足时，可以尝试申请更大的存储空间。
- 扩容可能需要将原有元素复制到新的存储区域。
- 使用完毕后需要释放动态申请的内存。

如果使用 `realloc` 扩容，需要正确处理扩容失败的情况，避免丢失原有内存地址。

**注意：** 动态分配不代表容量可以无限增长，扩容仍然受内存资源限制。

### 顺序表的特点

1. **随机访问：** 可以根据下标直接访问指定元素，时间复杂度为 \(O(1)\)。
2. **存储密度高：** 元素连续存储，不需要为每个元素额外保存链表指针。
3. **扩容不方便：** 静态分配的容量固定；动态分配虽然可以扩容，但可能需要申请新空间并复制元素。
4. **插入和删除不方便：** 在中间位置操作时，通常需要移动大量元素。

## 2.2.2_1 顺序表的插入与删除

### 插入操作

`ListInsert(&L, i, e)`：在顺序表的第 `i` 个位置插入元素 `e`。

假设顺序表当前有 `length` 个元素，插入位置为 `i`。

- 合法插入位置：`1 <= i <= length + 1`。
- 插入前必须确保顺序表尚有剩余容量。
- 为避免覆盖原有数据，需要从后向前移动元素。
- 插入完成后，`length` 加 `1`。

#### 插入算法

以下代码使用 C 语言指针传参，假设顺序表采用固定容量数组实现，且已经定义了 `SqList`。

```c
#include <stdbool.h>

bool ListInsert(SqList *L, int i, int e) {
    // 检查插入位置是否合法
    if (i < 1 || i > L->length + 1) {
        return false;
    }

    // 检查顺序表是否已满
    if (L->length >= MaxSize) {
        return false;
    }

    // 从后向前移动元素
    for (int j = L->length; j >= i; j--) {
        L->data[j] = L->data[j - 1];
    }

    // 插入新元素
    L->data[i - 1] = e;
    L->length++;

    return true;
}
```

#### 为什么必须从后向前移动？

例如，原顺序表为：

`[10, 20, 30, 40]`

在第 `2` 个位置插入 `99`。

需要先将 `40`、`30`、`20` 依次向后移动，再把 `99` 放到对应位置。

结果：

`[10, 99, 20, 30, 40]`

如果从前向后移动，可能会覆盖还没有移动的数据。

### 删除操作

`ListDelete(&L, i, &e)`：删除顺序表中第 `i` 个位置的元素，并通过 `e` 返回被删除的值。

合法删除位置：

`1 <= i <= length`

删除过程：

1. 检查删除位置是否合法。
2. 保存被删除的元素。
3. 将被删除元素后面的元素依次向前移动。
4. 将 `length` 减 `1`。

#### 删除算法

```c
#include <stdbool.h>

bool ListDelete(SqList *L, int i, int *e) {
    // 检查删除位置是否合法
    if (i < 1 || i > L->length) {
        return false;
    }

    // 保存被删除的元素
    *e = L->data[i - 1];

    // 后续元素向前移动
    for (int j = i; j < L->length; j++) {
        L->data[j - 1] = L->data[j];
    }

    L->length--;

    return true;
}
```

例如，原顺序表为：

`[10, 20, 30, 40]`

删除第 `2` 个元素 `20` 后：

`[10, 30, 40]`

删除后只需要将 `length` 减 `1`，不必专门清空最后一个数组位置，因为该位置已经不属于当前顺序表的有效元素范围。

### 插入与删除的复杂度

| 操作 | 时间复杂度 | 原因 |
|---|---|---|
| 按位访问 | \(O(1)\) | 可以直接计算元素位置 |
| 插入到表头 | \(O(n)\) | 需要移动原有元素 |
| 插入到表尾 | \(O(1)\) | 有剩余容量时不需要移动元素 |
| 删除表头元素 | \(O(n)\) | 后续元素需要前移 |
| 删除表尾元素 | \(O(1)\) | 只需调整表长 |

上述复杂度针对固定容量顺序表，且不计入扩容成本。插入和删除的具体开销还与操作位置有关。

## 2.2.2_2 顺序表的查找操作

### 1. 按位查找

按位查找是获取线性表中第 `i` 个元素的值。

在教材的算法描述中，可以表示为：

```c
ElemType GetElem(SeqList L, int i) {
    return L.data[i - 1];
}
```

实际使用 C 语言编写时，应先检查 `i` 是否在合法范围内，避免数组越界。

由于顺序表中的元素在内存中连续存放，可以根据起始地址、元素大小和下标计算目标元素的位置。

这叫作**随机存取**特性。

按位查找的时间复杂度为：

\[
O(1)
\]

### 2. 按值查找

按值查找是在表中查找具有给定值的元素，并返回其位序。

可以通过循环逐个比较元素：

```c
int LocateElem(SeqList L, ElemType e) {
    for (int i = 0; i < L.length; i++) {
        if (L.data[i] == e) {
            return i + 1;
        }
    }

    return 0;
}
```

注意：

- 数组下标从 `0` 开始，而线性表位序从 `1` 开始，因此返回 `i + 1`。
- 找到元素时，返回其位序。
- 找不到元素时，此处约定返回 `0`。
- 上述代码假设 `ElemType` 是可以使用 `==` 比较的类型，例如 `int`。

如果元素是结构体，C 语言不允许直接使用 `==` 比较两个结构体变量，需要根据实际需求比较其成员，或者编写专门的比较函数。

**考研算法题注意：** 伪代码中的比较操作可能会简化表达，但实际 C 语言代码仍需遵守 C 语言的类型规则。

## 2.3.1 单链表的定义（如何用代码实现）

### 1. 什么是链表？

链式存储是通过节点之间的链接关系来表示数据元素的逻辑顺序。

单链表的每个节点除了存放数据元素外，还要存储一个指向下一个节点的指针。

单链表的特点：

- **优点：** 不要求所有节点占用连续的存储空间；插入、删除时通常不需要像顺序表那样移动大量元素。
- **缺点：** 需要额外的空间存储指针；不支持像顺序表那样直接按位随机访问。
- **注意：** 链表插入和删除仍然可能需要先遍历查找目标位置。

### 2. 定义一个单链表

首先定义节点结构：

```c
typedef int ElemType;

typedef struct LNode {
    ElemType data;       // 数据域：存放数据元素
    struct LNode *next;  // 指针域：指向下一个节点
} LNode, *LinkList;
```

其中：

- `LNode` 表示一个节点类型。
- `LinkList` 是 `struct LNode *` 的别名，表示指向节点的指针。
- `data` 存储数据。
- `next` 指向下一个节点；如果当前节点是最后一个节点，则 `next == NULL`。

### 3. 不带头结点的单链表

不带头结点时，头指针直接指向第一个有效数据节点。

空表的判断条件：

```c
L == NULL
```

初始化代码：

```c
#include <stdbool.h>

bool InitList(LinkList *L) {
    *L = NULL;
    return true;
}
```

使用示例：

```c
void test(void) {
    LinkList L;
    InitList(&L);

    // 后续操作
}
```

这里的 `L` 是头指针，`&L` 是头指针本身的地址。

函数接收 `LinkList *L`，才能通过 `*L = NULL` 修改调用者的头指针。

### 4. 带头结点的单链表

带头结点时，链表最前面有一个不存放有效数据元素的头结点。

头指针指向头结点，头结点的 `next` 指向第一个有效数据节点。

空表的判断条件：

```c
L->next == NULL
```

初始化代码：

```c
#include <stdbool.h>
#include <stdlib.h>

bool InitListWithHead(LinkList *L) {
    *L = malloc(sizeof(LNode));

    if (*L == NULL) {
        return false;
    }

    (*L)->next = NULL;
    return true;
}
```

这里：

- `malloc` 用于申请头结点所需的内存。
- `*L` 是调用者的头指针。
- `(*L)->next = NULL` 表示头结点后面暂时没有有效数据节点。
- 初始化失败时返回 `false`。

使用示例：

```c
void test(void) {
    LinkList L;

    if (!InitListWithHead(&L)) {
        return;
    }

    // 后续操作

    free(L);
}
```

示例中的 `free(L)` 释放头结点；如果链表中已经创建了其他节点，需要先释放那些节点。

### 5. 两种实现方式的区别

| 对比项 | 不带头结点 | 带头结点 |
|---|---|---|
| 头指针指向 | 第一个有效数据节点 | 头结点 |
| 空表判断 | `L == NULL` | `L->next == NULL` |
| 是否有头结点 | 没有 | 有 |
| 插入、删除表头 | 通常需要修改头指针 | 通常可以通过头结点统一处理 |

**理解重点：** 头结点不是有效数据元素。它主要用于简化部分操作的实现。

## 2.3.2_1 单链表插入和删除

### 1. 插入操作

单链表插入的核心思想是：创建新节点，修改相关节点的指针，使新节点进入链表。

#### 按位插入

在第 `i` 个位置插入元素 `e`，通常需要先找到插入位置前面的节点。

- 不带头结点：插入第一个位置时，需要特殊处理头指针。
- 带头结点：可以将头结点视为第一个有效数据节点之前的节点，从而统一处理在表头插入的情况。

例如，原链表为：

`10 -> 20 -> 40 -> NULL`

在 `20` 后面插入 `30`，结果为：

`10 -> 20 -> 30 -> 40 -> NULL`

插入时，需要先让新节点指向原来的后继节点，再让前驱节点指向新节点，避免断开原链表。

### 2. 删除操作

单链表删除的核心思想是：找到待删除节点的前驱节点，修改前驱节点的 `next` 指针，跳过待删除节点，然后释放被删除节点占用的内存。

- 不带头结点：删除第一个节点时，需要修改头指针。
- 带头结点：可以通过头结点统一处理删除第一个有效数据节点的情况。
- 释放节点前，需要确保后续节点仍然能够被访问。
- 删除节点后，应使用 `free` 释放动态申请的内存，避免内存泄漏。

### 3. 本节理解重点

- 插入、删除操作主要修改节点之间的指针关系。
- 单链表不需要像顺序表那样整体移动后续元素。
- 但若要按位操作，通常仍需要遍历寻找对应位置。
- 修改头指针时，必须考虑是否需要通过二级指针传参。
- 使用动态内存创建节点后，应合理管理其生命周期。

## 2.3.2_1 单链表插入和删除（补充实现）

### 1. 按位插入

以**带头结点的单链表**为例，在第 `i` 个位置插入元素 `e`。

首先找到第 `i-1` 个节点，再将新节点插入到它后面。

```c
#include <stdlib.h>
#include <stdbool.h>

bool ListInsert(LinkList L, int i, ElemType e) {
    if (i < 1) {
        return false;
    }

    LNode *p = L;  // 从头结点开始
    int j = 0;

    // 找到第 i-1 个位置的前驱节点
    while (p != NULL && j < i - 1) {
        p = p->next;
        j++;
    }

    if (p == NULL) {
        return false;
    }

    LNode *s = malloc(sizeof(LNode));
    if (s == NULL) {
        return false;
    }

    s->data = e;
    s->next = p->next;
    p->next = s;

    return true;
}
```

注意：

- 带头结点时，头结点相当于第 `0` 个位置。
- 插入第一个有效数据元素时，前驱节点就是头结点。
- 必须先执行 `s->next = p->next`，再执行 `p->next = s`，否则可能丢失后续链表。
- 插入操作需要遍历寻找位置，时间复杂度为 \(O(n)\)；如果前驱节点已经给定，则插入本身为 \(O(1)\)。

### 2. 指定节点后插入

如果已经知道节点 `p` 的地址，可以直接在它后面插入新节点。

```c
bool InsertNextNode(LNode *p, ElemType e) {
    if (p == NULL) {
        return false;
    }

    LNode *s = malloc(sizeof(LNode));
    if (s == NULL) {
        return false;
    }

    s->data = e;
    s->next = p->next;
    p->next = s;

    return true;
}
```

该操作不需要遍历链表，时间复杂度为 \(O(1)\)。

### 3. 删除指定位置的节点

带头结点时，删除第 `i` 个有效数据节点，需要找到第 `i-1` 个节点，然后跳过待删除节点。

```c
bool ListDelete(LinkList L, int i, ElemType *e) {
    if (i < 1 || e == NULL) {
        return false;
    }

    LNode *p = L;
    int j = 0;

    while (p != NULL && j < i - 1) {
        p = p->next;
        j++;
    }

    if (p == NULL || p->next == NULL) {
        return false;
    }

    LNode *q = p->next;
    *e = q->data;
    p->next = q->next;
    free(q);

    return true;
}
```

删除过程：

1. 找到待删除节点的前驱节点 `p`。
2. 使用 `q` 保存待删除节点。
3. 让 `p->next` 指向 `q->next`。
4. 保存被删除元素的值。
5. 使用 `free(q)` 释放节点。

时间复杂度为 \(O(n)\)。

### 4. 删除指定节点的后继节点

如果已经知道前驱节点 `p`，可以直接删除它的后继节点。

```c
bool DeleteNextNode(LNode *p) {
    if (p == NULL || p->next == NULL) {
        return false;
    }

    LNode *q = p->next;
    p->next = q->next;
    free(q);

    return true;
}
```

时间复杂度为 \(O(1)\)。

### 5. 不带头结点的情况

不带头结点时，头指针直接指向第一个有效节点。

因此，插入或删除第一个节点时，必须修改头指针本身。此时可以通过 `LinkList *L` 传入头指针的地址。

```c
// 在第一个位置插入元素 e
bool InsertFirst(LinkList *L, ElemType e) {
    LNode *s = malloc(sizeof(LNode));
    if (s == NULL) {
        return false;
    }

    s->data = e;
    s->next = *L;
    *L = s;

    return true;
}

// 删除第一个节点
bool DeleteFirst(LinkList *L, ElemType *e) {
    if (L == NULL || *L == NULL || e == NULL) {
        return false;
    }

    LNode *q = *L;
    *e = q->data;
    *L = q->next;
    free(q);

    return true;
}
```

**易错点：** `L` 是头指针的地址，`*L` 才是头指针。要修改调用者的头指针，需要通过 `*L` 进行操作。

## 2.3.2_2 单链表的查找和建立

### 1. 按位查找

按位查找是获取单链表中第 `i` 个数据节点。

由于单链表不能随机访问，需要从头开始逐个遍历。

```c
LNode *GetElem(LinkList L, int i) {
    if (i < 1) {
        return NULL;
    }

    LNode *p = L->next;  // 跳过头结点
    int j = 1;

    while (p != NULL && j < i) {
        p = p->next;
        j++;
    }

    return p;
}
```

上述代码假设链表带头结点。

- 找到第 `i` 个节点，返回该节点的地址。
- 如果位置不合法或节点不存在，返回 `NULL`。
- 时间复杂度为 \(O(n)\)。

如果已经持有目标节点的地址，则不需要从头遍历。

### 2. 按值查找

按值查找是在链表中寻找数据域等于指定值的节点。

```c
LNode *LocateElem(LinkList L, ElemType e) {
    LNode *p = L->next;

    while (p != NULL) {
        if (p->data == e) {
            return p;
        }

        p = p->next;
    }

    return NULL;
}
```

时间复杂度：

- 最好情况：\(O(1)\)，第一个节点就匹配。
- 最坏情况：\(O(n)\)，需要遍历整个链表。

### 3. 单链表的建立

单链表建立的核心是：申请节点、赋值、连接节点。

#### 尾插法

尾插法每次把新节点放在当前链表的末尾，因此节点顺序与输入顺序一致。

```c
LinkList List_TailInsert(int n) {
    if (n < 0) {
        return NULL;
    }

    LinkList L = malloc(sizeof(LNode));
    if (L == NULL) {
        return NULL;
    }

    L->next = NULL;
    LNode *tail = L;

    for (int i = 0; i < n; i++) {
        LNode *s = malloc(sizeof(LNode));

        if (s == NULL) {
            // 释放已经建立的链表
            LNode *p = L;
            while (p != NULL) {
                LNode *q = p->next;
                free(p);
                p = q;
            }
            return NULL;
        }

        // 示例：将输入的数据写入节点
        // 实际使用时，可在此处通过 scanf 读取数据
        s->data = i + 1;

        s->next = NULL;
        tail->next = s;
        tail = s;
    }

    return L;
}
```

上例使用 `i + 1` 作为示例数据，实际输入时可以将 `s->data = i + 1` 替换成读取用户输入的代码。

尾插法的关键是始终维护尾指针 `tail`：

```c
tail->next = s;
tail = s;
```

如果每次都从头遍历寻找尾节点，建立整个链表可能需要 \(O(n^2)\) 时间；使用尾指针可以使建立过程达到 \(O(n)\)。

#### 头插法

头插法每次将新节点插入头结点之后。

```c
bool List_HeadInsert(LinkList L, ElemType e) {
    if (L == NULL) {
        return false;
    }

    LNode *s = malloc(sizeof(LNode));
    if (s == NULL) {
        return false;
    }

    s->data = e;
    s->next = L->next;
    L->next = s;

    return true;
}
```

例如，依次插入 `10`、`20`、`30`，最后链表为：

`30 -> 20 -> 10 -> NULL`

因此，**头插法会使新节点的顺序与插入顺序相反**。

### 4. 单链表的遍历与销毁

#### 遍历

```c
void ListPrint(LinkList L) {
    if (L == NULL) {
        return;
    }

    LNode *p = L->next;

    while (p != NULL) {
        printf("%d ", p->data);
        p = p->next;
    }

    printf("\n");
}
```

遍历带头结点的单链表时，从 `L->next` 开始，跳过不存储有效数据的头结点。

#### 销毁

```c
void DestroyList(LinkList *L) {
    if (L == NULL) {
        return;
    }

    LNode *p = *L;

    while (p != NULL) {
        LNode *q = p->next;
        free(p);
        p = q;
    }

    *L = NULL;
}
```

销毁时必须先保存后继节点，再释放当前节点。释放后不能继续访问已经释放的节点。

该函数适用于带头结点和不带头结点的单链表。

## 2.3.3 双链表

### 1. 双链表的定义

双链表的每个节点除了数据域，还包含两个指针：

- `prior`：指向前驱节点。
- `next`：指向后继节点。

```c
typedef struct DNode {
    ElemType data;
    struct DNode *prior;
    struct DNode *next;
} DNode, *DLinkList;
```

双链表可以向后遍历，也可以向前遍历。

特点：

- 相比单链表，可以方便地访问前驱节点。
- 每个节点需要额外存储一个指针，因此空间开销更大。
- 如果已经知道目标节点的位置，插入和删除通常可以在 \(O(1)\) 时间内完成。
- 如果需要先查找目标位置，查找仍然需要 \(O(n)\) 时间。

### 2. 初始化带头结点的双链表

```c
DLinkList InitDList(void) {
    DLinkList L = malloc(sizeof(DNode));

    if (L == NULL) {
        return NULL;
    }

    L->prior = NULL;
    L->next = NULL;

    return L;
}
```

这里头结点不存储有效数据。空表通过 `L->next == NULL` 判断。

### 3. 插入节点

在已知节点 `p` 后面插入新节点 `s`，需要同时修改前驱和后继指针。

```c
bool DListInsertAfter(DNode *p, ElemType e) {
    if (p == NULL) {
        return false;
    }

    DNode *s = malloc(sizeof(DNode));
    if (s == NULL) {
        return false;
    }

    s->data = e;
    s->prior = p;
    s->next = p->next;

    if (p->next != NULL) {
        p->next->prior = s;
    }

    p->next = s;

    return true;
}
```

插入时需要维护四个关键关系：

1. `s->prior = p`
2. `s->next = p->next`
3. 如果原来存在后继节点，让其 `prior` 指向 `s`
4. 让 `p->next` 指向 `s`

### 4. 删除节点

删除已知节点 `p`，要求 `p` 不是头结点。

```c
bool DListDelete(DNode *p) {
    if (p == NULL || p->prior == NULL) {
        return false;
    }

    p->prior->next = p->next;

    if (p->next != NULL) {
        p->next->prior = p->prior;
    }

    free(p);
    return true;
}
```

删除时需要将前驱和后继节点重新连接。

**易错点：** 如果删除的是最后一个节点，`p->next` 为 `NULL`，不能直接访问 `p->next->prior`。

### 5. 双链表与单链表的区别

| 对比项 | 单链表 | 双链表 |
|---|---|---|
| 指针域 | `next` | `prior`、`next` |
| 遍历方向 | 通常只能向后 | 可以向前、向后 |
| 存储开销 | 较小 | 较大 |
| 删除已知节点 | 通常需要前驱节点 | 可以直接通过 `prior` 找到前驱 |
| 指针维护 | 相对简单 | 需要同时维护两个方向 |

## 2.3.4 循环链表

### 1. 循环单链表

循环单链表的最后一个节点不指向 `NULL`，而是指向链表的第一个节点。

如果带头结点，则空表的头结点指向自己：

```c
L->next = L;
```

如果不带头结点，则空表通常用 `L == NULL` 表示；非空时，最后一个节点指向头指针指向的第一个节点。

特点：

- 从任意一个节点出发，沿着 `next` 可以循环访问节点。
- 遍历时不能简单地以 `p != NULL` 作为结束条件，否则会无限循环。
- 如果带头结点，可以从 `L->next` 开始遍历，并在再次遇到 `L` 时结束。

带头结点的遍历示例：

```c
void CircularListPrint(LinkList L) {
    if (L == NULL) {
        return;
    }

    LNode *p = L->next;

    while (p != L) {
        printf("%d ", p->data);
        p = p->next;
    }

    printf("\n");
}
```

### 2. 循环双链表

循环双链表同时具有双链表的前驱、后继指针和循环链表的首尾相连特征。

带头结点的空循环双链表：

```c
L->next = L;
L->prior = L;
```

非空时：

- 头结点的 `next` 指向第一个数据节点。
- 第一个数据节点的 `prior` 指向头结点。
- 最后一个数据节点的 `next` 指向头结点。
- 头结点的 `prior` 指向最后一个数据节点。

### 3. 循环链表的应用

循环链表适用于需要反复循环访问元素的场景，例如：

- 循环播放列表。
- 轮流处理任务。
- 约瑟夫环问题。

**注意：** 循环链表的关键是判断遍历终点，不能直接使用普通链表的 `p != NULL` 判断方式。

## 2.3.5 静态链表

### 1. 静态链表的定义

静态链表使用数组存储节点，并通过数组下标表示节点之间的链接关系。

它模拟了链表的链接结构，但不通过普通指针连接节点。

```c
#define MaxSize 10

typedef struct {
    ElemType data;
    int next;
} SNode;

typedef SNode StaticList[MaxSize];
```

其中：

- `data`：存储数据元素。
- `next`：存储下一个节点在数组中的下标。
- `MaxSize`：数组容量。

这里的 `next` 不是普通指针，而是数组下标。

### 2. 静态链表的示例

假设数组中：

| 数组下标 | `data` | `next` |
|---|---:|---:|
| 1 | 10 | 3 |
| 2 | 20 | -1 |
| 3 | 30 | 2 |

如果头节点的下标是 `1`，那么链接关系为：

`10 -> 30 -> 20 -> 结束`

其中 `-1` 表示链表结束。这只是示例约定，实际教材也可能使用其他结束标记。

### 3. 静态链表的特点

- 使用数组存储节点，不需要普通指针连接节点。
- 节点在数组中的物理位置不必与逻辑顺序一致。
- 插入、删除可以通过修改 `next` 下标完成，不一定需要移动大量数据。
- 数组容量固定，空间大小受到预先分配的限制。
- 与普通链表相比，静态链表不依赖动态申请每个节点的内存，但需要自行管理数组中空闲位置。

**理解重点：** 静态链表用数组下标模拟指针，因此也可以表示链式结构。

## 2.4 顺序表与链表的比较

### 1. 存储结构的区别

| 对比项 | 顺序表 | 链表 |
|---|---|---|
| 存储方式 | 元素连续存储 | 节点可以分散存储 |
| 访问方式 | 支持随机访问 | 通常需要从头遍历 |
| 按位访问 | \(O(1)\) | \(O(n)\) |
| 按值查找 | 一般 \(O(n)\) | 一般 \(O(n)\) |
| 插入、删除 | 中间位置通常需要移动元素 | 找到操作位置后通常只需修改指针 |
| 存储开销 | 不需要为每个元素额外保存链接指针 | 需要额外存储指针 |
| 容量变化 | 静态数组容量固定；动态顺序表扩容可能需要复制 | 通常可以按需申请和释放节点 |
| 空间局部性 | 通常较好 | 节点可能分散在内存中 |

### 2. 时间复杂度比较

| 操作 | 顺序表 | 单链表 |
|---|---|---|
| 按位访问 | \(O(1)\) | \(O(n)\) |
| 按值查找 | \(O(n)\) | \(O(n)\) |
| 在表头插入 | \(O(n)\) | \(O(1)\)，不计申请节点的开销 |
| 在表头删除 | \(O(n)\) | \(O(1)\) |
| 在表尾插入 | 有空位时 \(O(1)\) | 有尾指针时 \(O(1)\)，否则通常需要遍历 |
| 在已知前驱后插入 | 通常需要移动元素，最坏 \(O(n)\) | \(O(1)\) |
| 删除已知节点的后继 | 不适用指针链接方式 | \(O(1)\) |

注意：

- 表格中的链表插入、删除复杂度通常不包括寻找目标位置的时间。
- 如果需要先遍历寻找第 `i` 个位置，整体时间复杂度通常为 \(O(n)\)。
- 顺序表扩容可能涉及内存申请和元素复制，不能简单地认为扩容总是 \(O(1)\)。

### 3. 如何选择？

适合使用顺序表的情况：

- 经常根据下标访问元素。
- 数据规模相对稳定。
- 希望存储紧凑，减少额外指针开销。

适合使用链表的情况：

- 需要频繁进行节点插入和删除。
- 已经持有待操作节点或其前驱节点的地址。
- 数据规模变化较大，不希望依赖连续的大块存储空间。

**最终记忆：** 顺序表擅长按位访问；链表擅长在已知位置进行链接修改。但链表并不意味着所有插入、删除都更快，因为寻找位置本身可能需要遍历。

## 第二章总结

### 1. 核心知识

- 线性表：具有相同数据类型的有限序列。
- 顺序表：逻辑相邻的元素在物理位置上也相邻。
- 单链表：节点通过 `next` 指针连接。
- 双链表：节点通过 `prior` 和 `next` 两个指针连接。
- 循环链表：尾部重新连接到链表的起始位置。
- 静态链表：通过数组和下标模拟链式存储。

### 2. 高频易错点

1. 顺序表数组下标从 `0` 开始，线性表位序通常从 `1` 开始。
2. 顺序表插入时从后向前移动，删除时从前向后移动。
3. 单链表插入时先连接新节点的后继，再修改前驱节点的指针。
4. 释放节点之前，要先保存后继节点的地址。
5. 不带头结点的链表，在表头插入、删除时可能需要修改头指针。
6. 带头结点的链表，头结点不属于有效数据元素。
7. 循环链表遍历时需要使用正确的结束条件，避免无限循环。
8. 链表插入、删除的 \(O(1)\) 通常是指已经知道操作位置或相关节点时的复杂度。

### 3. 复杂度速记

| 操作 | 典型复杂度 |
|---|---|
| 顺序表按位访问 | \(O(1)\) |
| 顺序表中间插入、删除 | \(O(n)\) |
| 单链表按位访问 | \(O(n)\) |
| 单链表按值查找 | \(O(n)\) |
| 已知前驱节点后的单链表插入 | \(O(1)\) |
| 已知待删除节点前驱时的单链表删除 | \(O(1)\) |

以上复杂度均为典型情况，实际开销还与是否需要查找位置、是否涉及内存分配等因素有关。
